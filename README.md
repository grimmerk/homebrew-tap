# grimmerk/homebrew-tap

Personal Homebrew tap.

## presenterm-osc8

A fork of [presenterm](https://github.com/mfontanini/presenterm) that renders
markdown links as clickable OSC 8 terminal hyperlinks (see
[PR #908](https://github.com/mfontanini/presenterm/pull/908)).

```bash
brew install grimmerk/tap/presenterm-osc8
```

It installs a `presenterm-osc8` command so it coexists with the official
`presenterm` formula.
